Configuração do Firebase

Cole aqui as credenciais do seu projeto Firebase para sincronizar dados entre dispositivos. Encontre em: console.firebase.google.com → Configurações do projeto → Seus apps → SDK setup and configuration.

⚠ Permissão negada — ajuste as regras do Firebase:

No Firebase Console → Firestore Database → Regras, cole:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

E em Storage → Regras, cole:

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if true;
    }
  }
}

⚠ Atenção: estas regras permitem acesso público sem autenticação — use apenas em desenvolvimento ou enquanto não há dados sensíveis. Quando implementar autenticação, substitua if true por regras baseadas no usuário. Saiba mais sobre regras de segurança.
